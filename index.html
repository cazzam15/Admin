Before you start

  • Match the command word. Describe = detailed points · Explain = give reasons/consequences · Compare = both things side by side · Discuss = advantages and disadvantages · Justify = reasons for a choice.
  • One mark per developed point. A 4-mark question needs at least four different points.
  • Watch the clock. 50 marks in 90 minutes is under 2 minutes per mark.
  • Case study questions: write the problem, then its solution underneath. Don't repeat the same solution.
  • Mark yourself honestly. Only tick a point if your answer makes it clearly.

Exam tips

  • Know the command words. Describe, explain, compare, discuss and justify all need different kinds of answer.
  • Compare like with like. In "compare" questions, make each point about both things.
  • Use the key terms. Agenda, notice of meeting, minutes, quorum, data subject, SMART — examiners look for them.
  • Gantt chart ≠ action plan. Examiners report pupils mixing these up. Know the difference.
  • Nested IFs: start with the largest value and check whether you need > or >=. Use a VLOOKUP/HLOOKUP if a lookup table is given.
  • Totals queries: only add the tables you actually need — extra tables change the results.
  • Read every heading in an assignment spreadsheet before writing a formula, and always use cell references, never typed-in numbers.
  • Type your answers if your school allows it — markers can't award marks they can't read.
